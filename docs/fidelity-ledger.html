Fidelity Ledger

Does delegating a read to scripts/bulk-read lose information or introduce hallucination, compared to Claude reading the same file directly?

n = 1 iteration per question fixtures: real Go source, labstack/echo v5.3.1 baseline model: claude -p --model sonnet delegate model: bootsman/Spark/deepseek-ai/DeepSeek-V4-Flash-0731 real spend this run: $1.82

How this is measured

Five questions in evals/fidelity-questions.json, each with a ground_truth.must_mention list of exact identifiers extracted mechanically (grep) from the real fixture source, not written from memory. Three of the five are marked adversarial: picked because a summarizing delegate is likely to drop or flatten at least one item.

direct
Claude reads the file content inlined in the prompt and answers. The no-delegation baseline.
delegate
scripts/bulk-read's own raw answer — the delegate model's output, never seen by Claude.
final
Claude answers the same question using only the delegate's raw answer above (not the file). This is what a real user actually sees once the PreToolUse hook blocks a direct read and Claude falls back to bulk-read.

Scoring is exact/structured, not LLM-judged: recall is the fraction of must_mention items found as a case-insensitive substring of the answer. An item counts as an unsupported claim (a hallucination signal) if it appears in final but not in delegate's own raw text — the only source final had. This is a heuristic, not proof of fabrication: Claude can paraphrase a delegate claim in different wording and trip a false positive, so unsupported claims are a signal to inspect, not a final verdict — see the hallucination_check note in fidelity-questions.json.

On this run: no measurable fidelity loss, no hallucination.

All 5 questions (including all 3 adversarial ones, picked specifically because a summarizer is likely to drop an item) scored 100% recall on both the direct-read and delegated-read paths, and zero unsupported claims turned up in any final answer. The delegated (final) answers were also consistently cheaper on the Claude side: mean $0.138 vs. $0.227 for direct reads, because the delegate's already-condensed answer is far shorter than the raw file content Claude would otherwise have inlined.

Caveat: this is n = 1. A single pass per question is not enough to rule out an occasional dropped item or hallucination on a differently-phrased question, a larger file, or a different delegate model - it shows the mechanism works cleanly on these 5 specific questions, not that it's guaranteed to. Re-run with ITERATIONS>1 for statistical confidence before treating "delegation is lossless" as a settled conclusion; each iteration costs real money (~$1.8 for this 5-question set) so it wasn't run in a loop by default.
